# THE CITY: NO SIGNAL — Enhanced PSP / PPSSPP project

This update expands the original prototype with a larger city layout, more
building interiors, a perspective ray-cast renderer, procedural ambient audio,
radio messages, and a stalking entity behaviour system.

**Flashlight battery is unlimited.** Press Square to toggle it.

## Current controls
- D-pad: move
- Left analog stick: turn
- X: inspect nearby evidence
- Square: toggle flashlight
- Triangle: use radio
- Start: pause

## What's new
- 32x32 generated city grid with intersecting streets and building blocks
- Enterable building shells with internal partitions
- More convincing perspective rendering, facade seams, window bands and fog
- Multiple named districts: residential, office, industrial, central and subway
- Entity that advances while out of sight and retreats when directly faced
- Procedural low drone / static-like ambient audio generated by the PSP itself
- Additional field notes and radio transmissions
- Unlimited flashlight battery retained

## Build into EBOOT.PBP
This is a source project, not a precompiled EBOOT. A PSP homebrew compiler
(PSPSDK) is required.

1. Install PSPSDK on a computer.
2. Open a terminal in this folder.
3. Run `make`.
4. If the build succeeds, `EBOOT.PBP` will be created.
5. Put it in `PSP/GAME/THECITY/EBOOT.PBP` on a PSP memory stick, or point
   PPSSPP to the EBOOT.

## Technical note
The renderer is a software ray-caster that creates a perspective 3D-style
first-person view. It is not a full polygonal 3D engine. The city is still a
prototype-scale generated map, not the final enormous seamless city. Sound is
procedural and intentionally minimal; replace or extend it with recorded
ambience and spatial sound during later development.

## Automatic cloud build (no local PSP compiler needed)

A GitHub Actions workflow is included at `.github/workflows/build-psp.yml`.
It uses the official `pspdev/pspdev:latest` container image to run `make`
and uploads `EBOOT.PBP` as a workflow artifact.

To use it:
1. Create a GitHub repository and upload the contents of this ZIP.
2. Open the repository's **Actions** tab.
3. Select **Build PSP EBOOT** and click **Run workflow** (or push to main).
4. Wait for the job to finish successfully.
5. Open the completed workflow run and download the
   `THE-CITY-NO-SIGNAL-EBOOT` artifact.
6. Extract it. Put `EBOOT.PBP` in `PSP/GAME/THECITY/` or open it in PPSSPP.

The workflow has been added, but it has NOT been run from this environment.
A successful GitHub Actions run is still required to produce and verify the
actual EBOOT.PBP.
